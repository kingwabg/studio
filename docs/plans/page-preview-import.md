# 쪽 미리보기 — 불러오기·빼내기 (P1~P5)

작성 2026-10-29 · 대상 `rhwp-studio`(7700 캔버스 한컴) · 사용자 승인 완료(우선순위·저장위치·서식 범위)

## 배경
왼쪽 `쪽 미리보기` 패널은 쪽 단위 조작(새 쪽·복제·삭제·순서이동)만 있고,
**다른 문서의 쪽을 가져오거나**, **고른 쪽만 새 문서로 빼내는** 길이 없다.
사용자 요청(2026-10-29): ①패널 흰 바탕 ②썸네일 축소 ③불러오기 ④선택 쪽 빼내서 사이트 저장.

## 확정 사항 (사용자 승인)
- 순서: **P1(UI) → P2(불러오기) → P3(빼내기) → P4(사이트 저장) → P5(오류 처리)**
- 저장 위치: **문서함(`/documents`)** 우선, 드라이브는 추후 선택지로 확장
- 1차 서식 보장 범위: **본문 + 기본 표 + 이미지**. 각주·필드·머리말/꼬리말이 섞이면
  "일부 특수 서식(각주/머리말 등)은 제외될 수 있습니다" 토스트로 고지한다.

## 엔진 제약 (설계 근거)
- `@rhwp` wasm 에 **문서 삽입/쪽 범위 추출 API 없음** — `exportHwp/exportHwpx` 만 존재.
- HWP 에서 **쪽은 저장 단위가 아니라 조판 결과** → 쪽 경계 절단은 원리적으로 근사치다.

## 단계별 판정식

| 단계 | 내용 | 판정식 (완료 기준) |
|---|---|---|
| **P1** | 패널 흰 바탕 · 썸네일 축소 · [불러오기] 진입점 | DOM 실측: `.page-preview-panel` bg=`rgb(255,255,255)`, 폭 200px, 썸네일 종이 폭 ≤170px, `.page-preview-actions` 버튼 6개(불러오기 포함) |
| **P2** | 불러오기(A안: 보조 편집기 + 클립보드 왕복) — 다른 .hwp/.hwpx 로드 → 쪽 다중 선택 → 현재 문서의 선택 쪽 뒤에 삽입 | 2쪽 문서를 1쪽 문서에 삽입 후 `pageCount` 3, 삽입 구간 텍스트 일치, 원본 쪽 수 불변 |
| **P3** | 빼내기(B안: 임시 문서 재조립) — 선택 쪽만 담은 새 문서 생성 | 3쪽 선택 시 새 문서 `pageCount===3`, 원본 `pageCount`·바이트 불변 |
| **P4** | 사이트 저장 — 새 문서를 HWPX 로 `/documents` 업로드 | 업로드 응답 200 + `/documents` 목록에 1건 추가 + 내려받기 바이트 일치 |
| **P5** | 오류 처리 — 암호 문서·구형 HWP3·용량 초과·빈 문서 | 각 케이스 토스트 1회 + **원본 무변경**(pageCount·바이트 동일) |

## 예외 케이스 (자동/수동 검증 시나리오에 포함 — 사용자 지적)
1. **쪽 경계에 걸친 표**: 표가 쪽 나눔으로 분할된 문서를 빼내기 → 새 문서에서 표 조각 유지 여부 기록.
   - 기대: P3 1차에서는 **조각 유지**(문단 단위 절단) 또는 **잘림 고지** 중 하나로 확정하고 스펙에 명시.
2. **각주/머리말 포함 문서**: P2·P3 수행 시 고지 토스트가 1회 뜨고 작업은 계속된다.
3. **그림(이미지) 포함**: P1차 보장 대상 — 삽입/추출 후 이미지 개수 동일.
4. **암호 걸린 HWP**: 파일 선택 단계에서 거부 + 토스트, 원본 무변경.

## 리스크 / 미검증
- A안(클립보드 왕복)은 각주·필드·머리말에서 손실 가능 → 1차 범위 제한 + 고지로 처리
- 쪽 경계 절단은 근사 — 걸친 표의 시각적 정합은 C안(엔진 API) 전까지 보장하지 않는다
- P4 는 사이트 인증/권한(mock 단계) 영향 — 문서함 API 권한 확인 후 착수
