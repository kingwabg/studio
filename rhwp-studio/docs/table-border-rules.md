# 표 경계선·크기 조절 규칙 (정본 — 변형 금지)

사용자 확정 2026-08-04. 이 규칙과 어긋나는 변경은 사용자 재확인 없이 금지한다.

| # | 규칙 |
|---|---|
| 1 | 안쪽 경계선 일반 드래그 = 그 경계선이 실제 존재하는 구간 **전체** 이동, 표 크기 불변 |
2. 바깥 테두리(아래·오른쪽) = **칸마다 가운데 1/3 구간은 표 개체 선택**, 그 밖 구간은 **표 크기 조절**(그 줄 칸 크기를 절대값으로 지정 → 표 전체가 커지고 줄어듦). 위·왼쪽 테두리는 종전대로 개체 선택만. [2026-08-17 사용자 지시로 변경]
| 3 | 표 크기 조절 = 개체 선택 핸들 **오른쪽·아래·오른쪽아래 3개만** (파란 ■, 모서리 ●). 왼쪽·위 5자리 = 회색 ⃠ 상시 표시 + 금지 커서 |
| 4 | Shift+드래그 = 한 칸 경계만 어긋내기. 렌더 흉내 금지 — **그리드 재구성**(행/열 분할+스팬)으로만 |
| 5 | 경계선은 자기 축으로만 움직인다 (가로=상하, 세로=좌우). 다른 축의 선·붙은 끝점·표 바깥 크기는 불변 |
| 6 | 이동 한계 = 이웃 평행 경계선(닿으면 병합=치유)과 이웃 칸 최소 크기 |

구현 지점: `src/engine/input-handler-table.ts`(드래그 라우팅),
`src/engine/table-object-renderer.ts`(핸들), 엔진 `offsetCellBoundary`(그리드 재구성).

## 행 성장 예외 [2026-08-18 사용자 신고로 확장]

"안쪽 드래그 = 표 크기 불변"은 **보상이 가능할 때만** 성립한다. 행 안쪽 경계에서
이웃 행이 글줄 바닥(최소)이라 보상 축소가 불가능하면, 한컴처럼 아래 행을 밀어내며
대상 행만 키운다(표 높이 증가). 축소 방향은 글줄 바닥 규약대로 무동작.
